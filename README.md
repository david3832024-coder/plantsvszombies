# 🌻 Plants vs. Zombies (Web Edition)

一个完全使用原生 **HTML5 Canvas**、**Vanilla CSS** 与 **JavaScript** 纯手工打造的网页版《植物大战僵尸》。本项目无需借助任何大型前端框架，通过自研的渲染循环与物理引擎，在浏览器中高度还原了经典童年回忆。

## 🌟 核心特性 (Key Features)

* **🌊 动态波次系统 (5-Wave System)**
  游戏内置了循序渐进的 5 轮大波次攻击路线。开局拥有 500 启动资金的超高容错率，随着波次的推进，会按序解锁强大的进阶防守植物，直至迎接最终尸潮。
* **🎵 Native 像素级合成音效 (Web Audio API Synth)**
  **0 外部音频文件依赖！** 核心游戏代码内置了一个音频合成器。无论是种植植物的“啵”声、太阳掉落的清脆声，还是带有各种低通滤波算法的环境背景音乐、极其暴力的割草机轰鸣，都是在运行时由代码动态演算生成。
* **🗣️ 专属 AI 语音播报 (TTS Voice Announcer)**
  调用现代浏览器 Web Speech API，游戏在启动与新波次来临时，会自动触发元气满满的“添添，请做好准备！迎接战斗！”的中文语音播报。
* **🖥️ 响应式全屏渲染 (Responsive Canvas)**
  游戏采用了 100vw/100vh 强行铺满策略，并在事件系统中自动接管并转换 `getBoundingClientRect()` 映射逻辑，保证在任何宽屏或带鱼屏电脑上点击都能做到高帧率且 0 偏移精确判定。
* **🚜 终极防线 (Lawnmowers System)**
  完美重现经典的割草机救场机制。防线一旦被攻陷，红色大排量除草机将启动并秒杀当前道路的所有敌方单位。

## 🪴 植物兵工厂 (Arsenal)

1. **向日葵 (Sunflower)**: 每 6 秒产出专属阳光的完美经济核心。
2. **豌豆射手 (Peashooter)**: 攻速极快的初始输出主力。
3. **土豆地雷 (Potato Mine)**: 拥有 600 秒快速冷却周期的致命触底炸弹。
4. **坚果墙 (Wall-nut)**: 拥有 6000 HP 恐怖抗击打能力的不动明王。
5. **寒冰射手 (Snow Pea)**: 发射的冰晶豌豆能对僵尸挂上持续减缓速度的 Debuff。
6. **火爆辣椒 (Jalapeno)**: 以一己之力焚尽并秒杀一整行的群伤核武。
7. **樱桃炸弹 (Cherry Bomb)**: 九宫格范围毁天灭地的红色巨弹。

## 🧟 丧尸军团 (The Horde)

* **普通僵尸 (Normal Zombie)**: 基础炮灰。
* **路障僵尸 (Conehead Zombie)**: 戴着路障，额外增加了防护数值。
* **铁桶僵尸 (Buckethead Zombie)**: 获取了巨额耐久防护能力的重装刺客。
* **旗帜僵尸 (Flag Zombie)**: 扛着大旗的高速冲锋队长。游戏设定中它会以 50% 额外移速领跑尸潮。
*(所有僵尸自带受到物理碰撞弹射并在啃食时产生极其夸张的狂暴碎片效果)*

## 🚀 本地游玩方式 (How to Play Locally)

由于浏览器的安全跨域限制策略（为了正常激活 Canvas 的滤镜叠加、图片绘制能力以及语音播放），强烈推荐开启一个本地服务器再运行该项目。

在你的命令行/终端来到本目录后执行：
```bash
python3 -m http.server 8080
```
然后用浏览器打开 `http://localhost:8080/` 即可玩耍！

## ☁️ 部署到 Vercel (Deploy)

本项目为纯静态前端项目结构。你可以直接使用 Vercel CLI 执行零配置部署，10秒上线：
```bash
npm i -g vercel
vercel
```
或者直接将本文件夹推送到 GitHub 后进入 vercel.com 进行云端自动拉取构建。
